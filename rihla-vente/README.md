# Rihla — page de vente

Page de vente React (Vite) pour le **Pack Premium Débutant — Apprendre à lire le Coran**.

## Personnaliser

Éditez `src/config.js` :

- `price` / `compareAt` — tarif affiché
- `whatsapp` — numéro au format international sans `+` (ex. `229XXXXXXXX`)
- nom de boutique, titres, badge

## Lancer

```bash
npm install
npm run dev
```

La commande de commande ouvre WhatsApp avec un message prérempli. Le lien Google Drive du certificat n’est **pas** exposé sur la page publique.
